# Python-DA-Assignment---Data-Visualization



This project focuses on exploring the Taxis dataset and creating different visualizations using Python.

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## Work Done
- Loaded the Taxis dataset.
- Checked and handled missing values.
- Created Line, Bar, Pie, Histogram and Box plots.
- Created Count, Scatter, Heatmap, Pair and Violin plots.
